# Code of conduct

Treat contributors and users respectfully. Discuss ideas and evidence; do not attack people. Harassment, threats, discrimination, doxxing, sexualized conduct and unwanted contact are not accepted. Respect people's privacy and identities.

This applies to project issues, pull requests, reviews and other official project spaces. Maintainers may edit or remove harmful content, restrict participation, or ban participants according to severity and repetition. Decisions should be fair and proportionate; good-faith disagreement and bug reports are welcome.

Report conduct problems privately to the repository owner using an available private GitHub contact channel. Do not publish identifying information or sensitive evidence in an issue. If a private channel is unavailable, contact GitHub Support instead of disclosing personal details publicly. Maintainers will protect reporters' privacy as far as practical and will not retaliate against good-faith reports.
