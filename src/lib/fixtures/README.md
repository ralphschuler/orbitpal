# VRMA fixture

`greeting.vrma` is an original OrbitPal fixture under the repository MIT license, created for offline loader and storage checks. It contains a VRM humanoid T-pose skeleton, two clips (Hello 1.25 seconds; Smile 0.5 seconds), arm and hips motion, a happy expression and look-at rotation. It contains no mesh, image, audio or external resource. No third-party model or motion asset was copied.

`target-vrm0.vrm` and `target-vrm1.vrm` are original MIT fixtures of the same humanoid hierarchy with one triangle and a non-empty happy morph. They exercise the actual official VRM 0/1 loaders and retargeter without external textures or copied third-party models. The VRM-0 metadata uses the available CC0 identifier for its original geometry; the source fixtures are also freely available under the repository MIT license.
