## Known qualification blockers

The prior renderer smoke run
[39603124006](https://github.com/ralphschuler/orbitpal/actions/runs/39603124006)
failed during bootstrap. Its retained diagnostic shows GNOME 50 aborting while
trying to create a system-bus proxy; that harness deliberately supplies a
nonexistent system-bus address. It produced no qualified renderer measurements.
Connecting the isolated workload to the host system bus would change its scope
and is not a benchmark fix. This update instead prepares an empty private
compositor bus with no activatable host services. Its success still requires
a new actual GNOME smoke; the app domain retains no system-bus connection.

The prior macOS native run
[39604302545](https://github.com/ralphschuler/orbitpal/actions/runs/39604302545)
passed existing AX/AppleEvents/session prerequisites and observed one Main
window, but refused its initial UI inspection (`stage:1`, `code:5`,
`matched:0`). Cleanup was confirmed. It did not qualify Life or normal Stop/Quit;
the numeric result does not identify which ambiguity/tree guard refused.

These are failed acceptance environments, not successful product demos. The
release must keep Desktop Life experimental until the remaining evidence is
available. Open acceptance issues must not be bulk-closed merely because the
integration PR merges.
