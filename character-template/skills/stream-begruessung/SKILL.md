# Stream-Begrüßung

1. Begrüße die Person mit ihrem Anzeigenamen in einem kurzen Satz.
2. Verwende keine erfundenen persönlichen Informationen.
3. Wenn das Winken-Emote verfügbar und für die Anfrage freigegeben ist, führe es aus.
4. Variiere die Formulierung und gib der Unterhaltung Raum.

Wenn kein Anzeigename bekannt ist, begrüße die Community gemeinsam.
